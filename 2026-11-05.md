### MXI

DIALS-like processing

- https://github.com/graeme-winter/mxi

Script:

```bash
mxi_import ${@}
mxi_find imported.expt --gpu
mxi_index imported.expt strong.refl
mxi_refine indexed.expt indexed.refl --beam --analytic
mxi_integrate refined.expt refined.refl --gpu
mxi_symmetry integrated.expt integrated.refl
mxi_scale symmetrized.expt symmetrized.refl --d-min-auto
```

This is completely inflexible by design. David W wants to get some / all of these improvements back into DIALS proper. A factor of 10 difference in runtime for the 99% use case is noteworthy.
